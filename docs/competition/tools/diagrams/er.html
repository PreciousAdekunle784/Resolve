Resolve: database design (implemented schema)
15 tables across 4 migrations (supabase/migrations). Key columns only. Every user-owned table carries user_id and is protected by Row Level Security.

Every table that belongs to a user is linked to auth.users through user_id (cascade delete, so deleting an account deletes all its data). Not drawn individually, to keep the diagram readable. ai_analyses also links to evidence, and bank_responses to cases. Database triggers generate case numbers, log every status change, block changes to ownership fields, cap evidence at 10 files per case, and check that each submission belongs to the same user as its case and complaint.
