Resolve: implemented system architecture
Every component shown here exists in the codebase and runs in the deployed application (resolve-finance.vercel.app).

User's browser or phone

  • Responsive web app (React 19)
  • Forms, dashboards, case pages
  • Uploads evidence straight to private storage with a short-lived signed URL
  • Never receives secret keys
Resolve app · Next.js 16 on Vercel (server)

Pages & server actions

Server-rendered pages (dashboard, report wizard, case workspace, settings, admin); form actions validated with Zod

API routes (19)

Evidence, AI analysis, complaints, PDFs, submissions, replies, Gmail OAuth, scheduled job. Same-origin checks; per-user ownership checks

Session proxy

Refreshes the Supabase session cookie on every request; protects app pages

PDF generation

Complaint letters and account statements (pdf-lib)

AI orchestration layer

7 predefined, audited tools: identify bank · discover channels · generate complaint · validate · prepare email · analyse bank reply · recovery plan. Zod-validated outputs + grounding checks

Submission engine

Explicit authorisation · idempotency keys · atomic claim before sending · “Sent” only with provider proof · reconciliation of uncertain sends

Scheduled job (Vercel Cron, daily)

Resolves interrupted sends and checks Gmail threads for bank replies (secret-protected)

Supabase

Auth

Email + password accounts, JWT sessions, password reset

PostgreSQL · 15 tables

Row Level Security on every table (42 policies). Append-only case history. Triggers for case numbers, status logging and ownership checks

Storage · private “evidence” bucket

PNG / JPG / PDF only, 10 MB limit, owner-only folder policies, 5-minute signed links; server re-checks file contents

AI

AI provider (server-side only)

Google Gemini (deployed) or Anthropic Claude, behind one provider interface. Reads uploaded receipts and statements (document extraction), analyses cases, drafts complaints, explains replies

External

Gmail API (user's own account)

OAuth 2.0 + PKCE; send authorised complaints; optional read-only reply checks

Reference

Official guidance sources

CBN consumer-protection pages stored as links with a verification status; admin-curated bank contact channels

Secrets stay on the server
Supabase secret key, AI key, Google client secret and the token-encryption key are server-only environment variables.
Privileged access is narrow
The service-role key is used only for account deletion, encrypted Gmail tokens and recording provider-confirmed submission results, after an ownership check.
